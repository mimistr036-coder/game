# Папка для настоящих 3D-моделей

Сюда кладите `.glb`/`.gltf` файлы мотоциклов.

## Как подключить свою модель

1. Перетащите `.glb` файл в эту папку (Godot автоматически импортирует его).
2. В коде (например, в `garage_manager._refresh_bikes()` или в своей логике)
   получите узел `Motorcycle3D` и вызовите:

   ```gdscript
   bike_node.load_real_model("res://models/sportbike.glb")
   ```

3. Метод `load_real_model()`:
   - удаляет CSG-прототип;
   - инстанцирует импортированную сцену;
   - автоматически подгоняет масштаб так, чтобы высота модели была ≈1.3 м;
   - выравнивает модель по полу (Y=0);
   - возвращает `true` при успехе.

4. После загрузки можно снова вызвать `apply_data()`, чтобы обновить материал
   кузова (для этого импортированная модель должна иметь хотя бы один
   `MeshInstance3D` с материалом; по умолчанию после загрузки реальной модели
   цвет не перекрашивается автоматически, чтобы не испортить текстуры).

## Рекомендации по моделям

- Ось Y — вверх, ось X — вдоль мотоцикла (перед — в +X) или в -X: скрипт
  подгоняет масштаб по AABB, но ориентацию не крутит.
- Origin (точка привязки) — на земле по центру мотоцикла.
- Если в модели есть коллизия (`CollisionShape3D`), она будет использована
  для кликов в гараже. Если нет — добавьте её потом вручную к узлу RealModel.
