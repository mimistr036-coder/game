# Перекуп Мотоциклов — прототип на Godot 4 (GDScript, 3D)

Симулятор перекупщика мотоциклов: покупай на рынке → ремонтируй/тюнингуй в мастерской → продавай выгодно.

## Как запустить

1. Установите **Godot 4.2+** (стандартная версия с поддержкой 3D, подойдёт любой билд 4.x).
2. Откройте Godot → нажмите **Import** → выберите файл `project.godot` в этой папке.
3. Нажмите F5 — игра запустится со сцены `scenes/main.tscn`.

> Проект использует рендерер `gl_compatibility` (работает везде, включая слабые ПК).
> Графика — прототипная из `CSG*3D`-примитивов, но архитектура готова к замене на
> настоящие `.glb` модели (см. `models/README.md`).

## Структура проекта

```
res://
├── project.godot               # Конфиг (главная сцена + автозагрузки)
├── scenes/
│   ├── main.tscn               # Корневая сцена: 3D-гараж в SubViewport + UI
│   ├── garage.tscn             # 3D-гараж (пол, стены, ворота, свет, слоты)
│   └── motorcycle_3d.tscn      # Пустой Node3D со скриптом — строит CSG-мотоцикл
├── scripts/
│   ├── game_manager.gd         # Синглтон: деньги, день, репутация, гараж, рынок
│   ├── motorcycle.gd           # Класс Motorcycle (Resource): данные + расчёт стоимости
│   ├── market_generator.gd     # Процедурная генерация предложений
│   ├── garage_manager.gd       # 3D-гараж: слоты, клики, орбитальная камера
│   ├── motorcycle_3d.gd        # 3D-представление мото + load_real_model()
│   ├── market_ui.gd            # UI панели рынка
│   ├── workshop.gd             # Мастерская (ремонт/покраска/тюнинг)
│   ├── sell_menu.gd            # Продажа с торговлей
│   └── main.gd                 # Главный UI-контроллер, переключение экранов
├── models/                     # Кладите сюда .glb/.gltf модели
└── materials/                  # Пресеты материалов (StandardMaterial3D)
```

## Как устроены сцены (что редактор видит и как привязаны скрипты)

Все скрипты уже присоединены к узлам в `.tscn` файлах — **вам не нужно вручную
навешивать скрипты**. Вот иерархия для справки:

### `scenes/main.tscn` (открывается первой)

```
Main (Control) ← скрипт main.gd
├── GarageViewportContainer (SubViewportContainer) — растянут на весь экран
│   └── SubViewport (1200×800)
│       └── Garage ← экземпляр garage.tscn
├── TopBar (HBoxContainer)
│   ├── MoneyLabel  — «Баланс: 50000 ₽»
│   ├── DayLabel    — «День: 1»
│   └── RepLabel    — «Репутация: 50%»
├── BottomBar (HBoxContainer)
│   ├── MarketBtn   — открыть Рынок
│   ├── GarageBtn   — вернуться в Гараж
│   ├── ExpandBtn   — +1 слот за 30 000 ₽
│   └── NextDayBtn  — следующий день
├── MarketPanel (Control) ← скрипт market_ui.gd  (окно со списком карточек)
├── WorkshopPanel (Control) ← скрипт workshop.gd
└── SellPanel (Control) ← скрипт sell_menu.gd
```

### `scenes/garage.tscn`

```
Garage (Node3D) ← скрипт garage_manager.gd
├── Camera3D — орбитальная, управляется ПКМ + колесо
├── GarageGeometry (Node3D) — сюда скрипт добавляет пол/стены/ворота/свет
├── BikesAnchor (Node3D) — сюда ставятся мотоциклы по слотам
└── UIRoot (Control) — оверлей внутри 3D-вида (инфо о слоте, кнопки действий)
```

### `scenes/motorcycle_3d.tscn`

Пустой `Node3D` со скриптом `motorcycle_3d.gd`. Скрипт в `_ready()` строит прототип
из `CSGCylinder3D` (колёса, руль, выхлоп), `CSGBox3D` (рама, сиденье, вилка,
боковые панели) и `CSGSphere3D` (бак), навешивает материалы и `StaticBody3D`
для клика.

## Игровой цикл

1. **Стартовый капитал**: 50 000 ₽, день 1, репутация 50%, гараж 5/5 слотов.
2. Кнопка **«🛒 Рынок»** — открывает список из 3–7 мотоциклов на сегодня:
   бренд, модель, год, пробег, состояние, л/с, запрашиваемая цена и реальная
   стоимость. Подсвечиваются выгодные/завышенные предложения. Кнопка «Купить».
3. Кнопка **«🏠 Гараж»** — 3D-вид гаража.
   - **ЛКМ** по мотоциклу — выбрать (камера сфокусируется на нём).
   - **ПКМ + движение** — повернуть камеру. **Колесико** — зум.
   - Кнопки **«Отправить в мастерскую»** / **«Выставить на продажу»**.
4. **Мастерская**:
   - Ремонт двигателя (200 ₽ / единица состояния, 1 день за 25 ед.)
   - Тюнинг выхлопа (+15 л/с, 20 000 ₽, 2 дня)
   - Тюнинг подвески (+цена, 12 000 ₽, 1 день)
   - Покраска — 8 цветов (5000 ₽, 1 день)
5. **Продажа**: появляются 1–3 покупателя со случайными предложениями
   (±25% от реальной стоимости). Можно:
   - **Принять** сделку;
   - **Торговаться** (шанс успеха зависит от репутации, +10..20% при удаче; при неудаче покупатель может уйти или сбить цену на 10%);
   - **Отклонить** конкретное предложение;
   - **Новые покупатели** — пропустить 1 день.
6. **Репутация** растёт за каждую сделку и влияет на:
   - частоту свежих/редких мотоциклов на рынке;
   - честность цен продавцов;
   - количество и щедрость покупателей;
   - шанс успешного торга.
7. Расширение гаража: +1 слот за 30 000 ₽ (визуально подготовлены 10 позиций).

## Как заменить прототип на настоящие .glb модели

1. Положите `.glb` в папку `res://models/`.
2. Добавьте вызов в любом месте, где у вас есть доступ к `Motorcycle3D`-узлу, например в `garage_manager._refresh_bikes()` после `add_child(node3d)`:

```gdscript
node3d.load_real_model("res://models/sportbike.glb")
```

Метод автоматически:
- удалит CSG-прототип;
- инстанцирует импортированную сцену;
- посчитает AABB по всем `MeshInstance3D` внутри и подгонит масштаб под высоту 1.3 м;
- выровняет по земле (Y=0).

Подробности см. в `models/README.md` и в комментариях к `scripts/motorcycle_3d.gd`.

## Управление в сцене гаража

- **ЛКМ** по мотоциклу — выбрать.
- **ПКМ + мышь** — вращать камеру.
- **Колесико мыши** — приблизить/отдалить.

## Что можно расширять

- Разные модели под разные бренды (`brand → путь к glb`).
- Аудио-звук двигателя в гараже.
- Анимации открытия ворот при переходе на рынок.
- Больше апгрейдов (турбонаддув, новая резина и т.п.).
- Систему сохранений (`ResourceSaver.save(GameManager, ...)`).
